# mk-site-resource

## 项目简介

`mk-site-resource` 是一个用于归档和发布多个独立 HTML 页面的仓库。本仓库不针对任何特定域名或网站，仅作为静态资源的集合存储与版本管理用途。

## 目录结构

```
mk-site-resource/
├── pages/               # 存放各独立 HTML 页面
│   └── ...              # 按需命名的页面文件或子目录
├── assets/              # 页面所引用的公共资源（CSS、JS、图片等）
│   ├── css/
│   ├── js/
│   └── images/
├── index.html           # 仓库首页（可选，用于导航或展示）
└── README.md            # 本文件
```

- **pages/**：存放所有独立的 HTML 页面，可根据需要以子文件夹形式组织。
- **assets/**：存放页面引用的公共样式、脚本和图片资源，便于统一维护和更新。
- **index.html**：可放置一个简单的索引页面，用于快速访问仓库内各页面（非必需）。

## 页面归档说明

- 每个 HTML 页面均为独立可运行的静态文件，不依赖外部服务器或后端服务。
- 页面之间无硬性关联，可根据需要单独引用或部署。
- 资源引用建议使用相对路径，以保证在本地或静态托管服务中均能正常访问。

## 维护说明

- **新增页面**：在 `pages/` 目录下创建新的 HTML 文件或子目录，并将相关资源放置于 `assets/` 对应目录中。
- **更新资源**：修改 `assets/` 下的文件后，请同步更新引用该资源的页面链接。
- **版本管理**：建议在提交时附带简要说明，便于追溯变更内容。
- **清理归档**：不再使用的页面或资源可移除或移至 `archived/` 目录（如需可自行创建）。

## 使用方式

1. 克隆本仓库到本地：
   ```bash
   git clone https://github.com/your-username/mk-site-resource.git
   ```
2. 在 `pages/` 中添加或编辑 HTML 文件。
3. 通过浏览器直接打开 HTML 文件，或部署至任意静态托管服务。

## 注意事项

- 本仓库仅用于静态 HTML 资源的归档与发布，不包含任何动态逻辑或后端服务。
- 请勿在仓库中存放敏感信息或违反相关法律法规的内容。
- 资源引用路径请保持相对一致，避免因部署位置变化导致加载失败。
